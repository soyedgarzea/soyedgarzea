# Domain Model

Site is statically rendered from typed local data.

- `Profile`: localized biography and role statement.
- `ExperienceItem`: role, company, technologies, localized summary, and highlights.
- `EducationItem`: institution and localized program.
- `HobbyItem`: localized title and description.
- `ProductItem`: marketplace, localized category, optional opinion, image, and referral URL.

Missing optional product fields render explicit coming-soon states. No database or CMS is required.
