# Project Inputs

The template does not decide product-specific behavior. A consuming project must provide the real
inputs listed here.

## Required Inputs

- Project name.
- Repository owner and repository name.
- Brand and content direction.
- Domain model.
- Design-system requirements.
- Authentication requirements.
- Analytics requirements.
- Deployment provider and environment mapping.
- Required environment variables.

## Rule

Do not invent these values inside the template. Keep placeholders until a real project supplies the
current project data.
